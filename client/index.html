Rock, paper, scissors on a 9×9 board, played by your code.

You don't move the tokens yourself. You write a small JavaScript bot with the ottv2 library and submit it. Once two bots are seated, the server plays the whole match and streams every move live to the players and anyone watching.

The rules

  • Each player has 6 rocks, 6 papers and 6 scissors, placed at random. Red gets rows a–c and Blue gets rows g–i. Rows d–f start empty.
  • Players take turns. On your turn, move one token to any of its 8 neighbouring cells, diagonals included. You can't move onto your own token.
  • Moving onto an enemy token starts a battle. The winner stays on the cell and the loser is removed. Ties are not allowed, so you can't move onto a token of the same type.
  • You win by getting a token to the far corner (i9 for Red, a1 for Blue) or by removing every enemy token.

Server rules: Red moves first. A bot that crashes, takes too long or plays an illegal move forfeits. A player with no legal moves loses. After 400 moves, the player with more tokens wins.

    Writing a bot with ottv2

    A bot is a JavaScript file with a move(game) function. Each turn the server calls it with the current position and plays whatever move it returns. The library has the rules engine, so game.legalMoves() always matches what the server accepts.

    Quick start

    This is a complete bot. It captures when it can win a battle, and otherwise makes a random move:

    const OTT = require('ottv2');

function move(game) {
  const moves = game.legalMoves();
  const capture = moves.find((m) => m.outcome === 'win');
  return capture || OTT.random(moves);
}

    require('ottv2') is the only import available. The library is also a global called OTT, and it's passed as a second argument: move(game, OTT). You can define move as a plain function, or export it with module.exports = move or exports.move = move.

    What to return

    Return any one of these. They all mean the same move:

    • an item from game.legalMoves() (recommended)
    • an object { from: 'c3', to: 'd4' }
    • a string such as 'c3 d4', 'c3-d4' or 'c3d4'
    • an array ['c3', 'd4']

    How a match runs

    • The first player to submit is P1 · Red. Red starts on rows a–c, moves first, and races for i9. The second player is P2 · Blue, starts on rows g–i, and races for a1.
    • When you submit, the server checks your bot on a test board. If it doesn't load or can't make a legal first move, you get the error right away, with a line number.
    • During the match each bot runs in its own sandboxed process. It has 1000 ms per move and 64 MB of memory, with no network or file access. Top-level variables persist between turns, so you can keep state across moves.
    • If a bot throws an error, runs out of time or memory, or returns an illegal move, it forfeits. The reason is written to the log.
    • Output from console.log goes into the match's server log (up to 20 lines per turn). console.log(game.toString()) prints the board.
    • The game ends when a token reaches the opposite corner, when one side has no tokens left, or when the player to move has no legal moves (that player loses). After 400 moves, the player with more tokens wins. Equal counts are a draw.

    The game object

    move(game) receives an OTT.Game. Tokens are frozen objects { id, owner, type, cell }: owner is 1 or 2, type is 'rock', 'paper' or 'scissors', and cell is a name like 'e5'.

    game.meYour player number, 1 or 2.
    game.opponentThe other player's number.
    game.turnWho is to move. During your call this equals game.me, but it changes in positions you get from after().
    game.plyNumber of moves played so far (both players).
    game.maxPliesThe move limit (400).
    game.myTarget / game.opponentTargetThe corner you need to reach ('i9' or 'a1'), and theirs.
    game.at(cell)The token on cell, or null.
    game.tokens(player?)All tokens, or only one player's.
    game.myTokens() / game.opponentTokens()Shortcuts for tokens(me) and tokens(opponent).
    game.count(player, type?)How many tokens a player has left, optionally of one type.
    game.legalMoves(player?) Every legal move as { from, to, token, defender, outcome }. outcome is 'move' (empty cell), 'win' (you capture defender) or 'lose' (your token is removed).
    game.movesFrom(cell)Legal moves for the token on one cell.
    game.threats(cell, type)Enemy tokens next to cell that would beat a type token there, i.e. what could capture you if you moved there.
    game.validate(move)null when the move is legal, otherwise the reason it isn't.
    game.after(move)A new Game with the move played. The original isn't changed. Use it for lookahead.
    game.isOver, game.winner, game.reasonFor positions from after(). winner is 1, 2, 0 (draw) or null.
    game.history / game.lastMoveMoves so far: { ply, player, id, type, from, to, outcome, defender }.
    game.toString()The board as text: Red in capitals (R P S), Blue in lowercase.

    Library functions

    OTT.beats(a, b)true if type a beats type b.
    OTT.battle(attacker, defender)'win', 'lose' or 'tie'.
    OTT.counter(type)The type that beats type: counter('rock') === 'paper'.
    OTT.neighbors(cell)The up to 8 cells touching cell.
    OTT.distance(a, b)How many moves it takes to get from a to b (diagonals count as one).
    OTT.coords(cell) / OTT.cell(row, col)Convert between 'c4' and { row: 2, col: 3 } (zero-based).
    OTT.other(player)1 → 2, 2 → 1.
    OTT.random(list)A random item of list.
    OTT.ROCK, OTT.PAPER, OTT.SCISSORS, OTT.TARGETSConstants. TARGETS[1] === 'i9', TARGETS[2] === 'a1'.

    Testing locally

    If you have this project checked out, you can pit two bot files against each other in the same sandbox the server uses:

    node server/tools/play.js my-bot.js library/examples/greedy.js
node server/tools/play.js my-bot.js library/examples/random.js --games 20

    You can also use Test my bot in the submit dialog. It runs your bot on a test board and shows its output without joining a match.
